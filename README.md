# Personal Finance Tracker

A full-stack web application for tracking and managing personal finances.

## Live Website

https://trackery.infinityfreeapp.com/login.php

## Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Features

- User registration and login
- Add financial transactions
- Edit and delete transactions
- View financial records
- User-specific data
- CRUD functionality
- Database integration

## About

This project was created as a personal full-stack web application to practice
backend development, database management, user authentication, and CRUD operations.
